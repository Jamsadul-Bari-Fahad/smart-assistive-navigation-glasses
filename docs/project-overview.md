# Project Overview

## Project Title
Smart Assistive Navigation Glasses for Visually Impaired People

## Project Purpose
The project aims to develop a wearable assistive navigation system
that helps visually impaired people understand their surroundings
and receive timely obstacle warnings.

## Main Components
- ESP32-S3 Sense
- Camera module
- ToF distance sensor (initially considering VL53L0X)
- Vibration motor
- Audio feedback
- Wi-Fi communication
- Cloud-based vision AI API

## System Concept
The camera captures environmental images while the distance
sensor measures nearby obstacles.

The ESP32 handles immediate sensor processing and vibration
warnings. A Python backend supports image processing,
cloud AI communication and spoken environmental descriptions.
